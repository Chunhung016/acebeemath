# ACEBEE Math Adventure

一个无需账号、可直接在浏览器中游玩的少儿数学冒险游戏，适合 7–12 岁学习加、减、乘、除。

## 开始游戏

下载或克隆仓库后，直接双击 `index.html`。无需服务器、安装或网络连接。

请保留 `images/` 文件夹，它包含游戏使用的全部 PNG 美术素材。

## 游戏内容

- 拖拽操作：将可见物品放入背包、篮子、花盆、鱼缸等容器；每件物品都能数清、拖回和重新分组。
- 看图列式：从分组图片填写算式，例如 5 组、每组 4 个，对应 `5 × 4 = 20`。
- 答题训练：选择、数字输入、连线三种方式。
- 混合挑战：十道题组合不同操作和数学概念。
- 自带轻柔音乐、静音开关、难度与场景选择；本地保存星星和等级。

## 主要文件

- `index.html`：完整离线游戏。
- `images/`：吉祥物、容器、计数物件、背景和奖励素材。
- `使用说明.md`：中文玩法与技术说明。

## 运行测试（开发用）

项目的浏览器回归测试位于 `tests/`，普通游玩不需要 Node.js 或测试依赖。
